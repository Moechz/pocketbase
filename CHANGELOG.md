# Changelog

All notable user-visible changes to the PocketBase TOS application package.

## 0.26.6-1 — 2026-11-12

### Added
- First release. PocketBase (`argonptg/pocketbase:0.26.6`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8085 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/pocketbasedocker/`.
